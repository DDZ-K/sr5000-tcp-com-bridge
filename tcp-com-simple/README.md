# SR-5000 扫码串口桥接 v1.3.0-field.1 虚拟串口准备版

## 新建虚拟串口（无需电脑恰好已有串口）
1. 先断开桥接并关闭目标软件占用的串口。主界面点击 **创建虚拟串口**。
2. 窗口显示桥接端（本工具打开）、软件端（目标软件打开）。下拉提供经系统现有COM及COM Name Arbiter保留表排除的建议，也可手填；创建时仍会重新检查真实驱动库存，不覆盖已有或保留端口。已有可用对优先保留，仍可在主界面用 **配对设置** 核验/配置。
3. 缺驱动时，只有真实 **Windows 7 x64** 可以明确点击 **安装驱动**。程序固定使用同目录 `drivers/win7-x64/Setup_com0com_v3.0.0.0_W7_x64_signed.exe`，先校验固定SHA256及Authenticode，再人工确认和系统UAC。校验失败不会启动。安装器界面的选项由现场人员核对，不要重复创建已有对。
4. **Win10/11拒绝安装包内Win7驱动**；请采用现场已获批的适配驱动。若已预装可信setupc，仍能创建串口对。不关闭驱动签名/安全启动。安装器退出码不代表驱动已就绪：程序仅重新检查受管理员保护的setupc，重启/驱动实际加载仍需现场确认。
5. 安装后再明确点击 **创建串口对**，核对两端方向并确认管理员操作。异步等待不强杀、不重复创建。只有真实库存回读确认同一配对及安全信号配置后，才回填主界面COM；失败在准备窗口日志和主日志说明，绝不自动连接TCP或发送指令。
6. 关闭准备窗口，目标软件选择软件端，两端串口参数一致，再手动 **保存并连接**。真实扫码枪/虚拟串口/软件全链路与Win7驱动安装需现场验收，本机模拟不是硬件验收。

构建：MSVC x64开发环境运行 `build.bat`（静态CRT、C++14、`/W4 /WX`、Win7子系统、NDEBUG测试）。本机若标准vcvars缺失，可运行 `python build_local.py`，使用已发现的VS ScopeCppSDK/vc15 x64工具链；不会安装工具链或驱动。设置 `SR5000_TEST_DRIVER` 为已交付安装器绝对路径，可在全套测试中额外只读校验实际SHA256/Authenticode及临时副本文件锁，不执行安装器。

以下保留此前版本功能/升级说明；新版标题为v1.3.0-field.1。

用户已明确现场使用扫码枪单一TCP服务端监听端口，本程序作为客户端在同一条连接收发。本版只显示一个“通讯端口”，不把客户端系统分配的本地端口当作配置。服务器/客户端角色本身并不保证所有设备只用一个监听端口；这里只实现用户已经确认的现场拓扑。

## 改动
- 一个通讯端口，同时用于发送触发与接收扫码；状态合并为TCP连接和串口转发两卡。
- 删除主界面“共用连接原样转发”勾选及启动设置中的共享确认项。启用串口时，接收的数据默认原字节转到已核验串口，包含可能的设备命令应答；不擅自猜测过滤、不加删换行。
- 博世Logo改为黑白图形标，没有BOSCH字样；主窗口及程序图标均更新，资源嵌入EXE。
- 保留现有COM端点选择、按键触发、ASCII/HEX转换、一次启动连接/托盘和故障不重放逻辑。
- 通信引擎和串口/编解码/配对模块逐段/逐文件保持与此前已验证版本一致。仅操作界面、配置入口固定为一条双向TCP，不重新设计通信实现。

## 升级
1. 退出旧桥接及其托盘实例，保留旧目录。解压新包到新目录。
2. 复制旧tcp.ini保留现场IP、端口、指令、COM和串口参数。旧ReceivePort与SendPort相同时自动显示成一个通讯端口；若旧两端口不相同则留空，必须人工确认，不猜选其中之一。新的CommunicationPort键优先；保存时也写入相等的两个旧键，便于旧版回退。
3. 若以前配置过启动选项，可复制startup.ini保留自动连接、后台键、托盘和延迟设置；旧Shared/Signature字段不再控制连接。打开SR5000TcpComBridge.exe，确认标题v1.3.0-field.1。
4. 工具打开“桥接端”COM，目标软件打开同一对的“软件端”COM。例如现场已验证桥接COM8、软件COM7，保持两端参数一致。不要重新安装驱动、创建/删除已可用配对。
5. 点“保存并连接”，按已选触发键使用。本版不再有“启用转发”开关，工具始终按TCP→COM用途工作；串口配置无效会拒绝连接/触发，不允许切回只测TCP模式。

## 自启动
右上角“启动设置”可选当前用户登录Windows后自启动、启动时尝试连接一次、恢复后台键、收起到托盘和延迟秒数。开启/关闭都必须点击应用；不会因为打开本工具自动注册。更换到新目录后重新应用启动设置，若原启动项指向旧目录，会要求明确确认替换，不能同时运行两个版本。
不是登录前服务，不自动提权，不在开机时自动发送触发，不重放旧码，不默认循环重连。最小化收起托盘，点X仍退出。现场Windows重启和驱动权限时序须现场验收。

## v1.2.2 默认始终转发
