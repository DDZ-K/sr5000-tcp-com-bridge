# SR-5000 扫码串口桥接 v1.2.0 界面版

用户已在现场确认v1.1.2通信有效；本版旁路保留旧版，TCP引擎、串口实现、编解码和配对逻辑与v1.1.2逐段/逐文件对比一致，只增加界面与明确可选的启动生命周期功能。仍为Win7 x64原生EXE，不改为依赖Win10/.NET8的程序。

## 界面
浅色卡片式：扫码接收、触发发送、串口转发三张状态卡，原字节计数，TCP/串口参数分区，蓝色主操作和轻量日志。顶栏及程序图标采用按用户要求处理的红色博世图形标，不带BOSCH字样，不在标题下添加装饰小字。图形源于博世官网资产，出处见源码assets/SOURCE.json；不表示本程序为博世官方出品。

## 升级与现场参数
1. 手动退出旧桥接/旧TCP调试工具，保留旧目录以便回退。新目录解压本包，打开 SR5000TcpComBridge.exe；标题应为v1.2.0。
2. 从功能已验证的旧目录复制tcp.ini到新目录，保留真实IP、两个设备端口、触发编码/字节及COM参数；不要用空白示例覆盖现场配置。
3. 仍是工具写桥接端COM，另一软件读取同一虚拟对的另一端；例如已核验的一对中工具COM8、目标软件COM7，两端串口参数一致。TCP同端口继续使用一条双向连接，并保留“共用连接原样转发（含应答）”的明确确认。
4. 不删除其他虚拟端口，不重新创建已正常配对，不重装驱动。原回车触发、主动按钮、HEX/ASCII转换、收到原字节立即转发、独立命令应答隔离、故障锁定/不补旧码均保留。

## 开机自启动（当前用户登录后）
默认关闭。先把整个文件夹放到不会移动的固定目录，配置并“保存并连接”验证正常，再点右上角“启动设置”。
- 勾“开机自启动（当前用户登录Windows后）”，点“应用设置”后，程序仅为当前用户写入HKCU Run中本工具自己的注册值，并回读核对；不建服务、不创建计划任务、不改其他应用的启动项。取消勾选再应用可移除。已有另一目录的本工具启动项会先要求明确确认，不擅自覆盖。
- 如果还需要启动后直接工作，勾“启动时自动连接已保存配置”和“启动时启用所选后台按键”。可选择0/5/10/20/30秒延迟（默认10秒）。只尝试连接一次，不自动重复业务指令或扫码内容；配置无效或故障时须人工处理。
- 你使用同端口TCP并启用COM时，还需在主界面确认共用流含应答的风险并保存参数，然后在启动设置明确勾选“自启恢复当前共用连接转发确认（含应答）”。这个授权绑定保存的IP/端口/COM及串口参数；参数发生变化时旧授权不匹配，自动连接被拒绝，不偷偷放宽。
- “启动后收起到系统托盘”为可选项。平时最小化会收起到托盘，单击/双击托盘图标恢复；托盘右键可显示、断开、退出。关闭主窗口的X仍是退出，不悄悄改成继续运行。故障有托盘提示。
- 这是登录桌面后的应用，不是登录前服务，后台键盘也需要登录会话。程序不自动提权；如果工位驱动/备用setupc检查仍要求管理员，会显示权限故障，不能宣称普通Run项自动获得管理员权限。不要关闭UAC/签名来凑自启动。
- startup.ini独立保存启动选项，tcp.ini仍保存通信配置；升级时应一并保留。移动EXE后需要在新位置重新应用自启动设置。

## 验证范围
- 严格/W4 /WX构建，NDEBUG完整原通信回归，以及GUI→40字节Enter→真实本机TCP→明确模拟串口文件通过。
- 自启动注册/删除/路径空格与中文引号、其他目录保护、配置原子写失败与授权变更，在临时HKCU测试键中执行并回读/清理；真实Windows Run值测试前后核对未改变。开发电脑未注册本工具自启动。
- 以实际最终EXE从空目录启动--autostart，真实本机TCP服务器接到连接，验证启动时没有业务发送、后台按键选项恢复、接收探针显示、手动按钮发送字节准确、正常退出。不是只验证辅助函数。
- 启动日志更新不能取消待执行连接；操作员断开或改配置会取消待执行启动任务，已排队的旧定时消息不能在取消后又连接。此类回归均覆盖。
- 最终EXE真实启动并分别捕获主界面和启动设置，确认Logo无字、控件无裁切，关闭的只是测试启动的本程序。截图不是效果图。
- 通信核心文件与现场确认v1.1.2保持一致，但未在现场Win7重启验收，也未在开发机安装真实串口驱动/连接真实扫码枪。系统重启、现场权限、目标软件开串口时序仍需现场确认。

## 驱动与回退
包内仍附先前验证来源/签名的Win7 x64 com0com安装器、完整上游源码、GPL许可；不表示适配Win7 x86或Win10/11内核驱动。已有可用驱动不要重装。
回退先关闭本版；若已开启自启动，先在“启动设置”取消并应用，再运行保留的v1.1.2目录。不要同时开启多个版本争抢TCP/COM。

## 源码与编译
仓库tcp-com-ui/，并保留tcp-com/及tcp-only/。MSVC x64开发环境需cl.exe及Windows SDK rc.exe可用；build.bat嵌入资源/图标/manifest并运行回归。发布ZIP只需EXE、配置、说明和可选驱动资料，Logo不需要外置图片或联网加载。
